Требование:
Написать серверный модуль управления ботами (новый Spring-сервис или отдельный
модуль внутри существующего бэкенда). Требования:
  1. REST API для управления ботами:
       POST /bots/start       — запустить N ботов на канал
       POST /bots/stop        — остановить всех или конкретного бота
       GET  /bots/status      — список ботов и их текущий статус
       POST /bots/{id}/send   — вручную отправить сообщение от бота
  2. Диспетчер ботов: компонент, хранящий состояние всех активных ботов в памяти
  3. Каждый бот — отдельный управляемый объект с полями: id, статус, канал, прокси, аккаунт
  4. Логирование действий каждого бота в БД (таблица bot_logs)
  5. Graceful shutdown: при остановке сервера все боты корректно отключаются

Ожидаемое время выполнения: 3-4 дня

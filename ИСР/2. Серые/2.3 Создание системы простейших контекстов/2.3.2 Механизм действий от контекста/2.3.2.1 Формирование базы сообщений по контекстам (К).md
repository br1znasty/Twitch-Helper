Требование:
Сформировать и загрузить в БД начальную базу сообщений для ботов:
  1. Для каждого типа контекста (из задачи 2.3.1.1) написать минимум 15-20 сообщений,
     которые бот может отправить (разнообразные, не копипаста)
  2. Каждое сообщение в таблице context_messages: context_type, message_text, weight
     (weight — вероятность выбора, чтобы редкие сообщения шли реже)
  3. Сообщения должны выглядеть естественно: без орфографических ошибок, без спама,
     соответствовать тематике контекста (игра, стрим, активность и т.д.)
  4. Загрузить базу через SQL-скрипт (seed data) или через UI
  5. Предусмотреть возможность добавления новых сообщений через UI в будущем

Ожидаемое время выполнения: 1-2 дня

Требование:
Реализовать компонент ContextCollector:
  1. Переодически (раз в 30 сек) опрашивать Twitch API для получения данных стрима
  2. Читать последние 50 сообщений из IRC-чата (накопленный буфер)
  3. По правилам из тех. дока (задача 2.3.1.1) определять текущий тип контекста
  4. Хранить текущий контекст в памяти (и/или кешировать в Redis/таблице)
  5. Предоставлять метод getCurrentContext(channel): String
  6. При смене контекста — записывать в bot_logs событие context_changed

Ожидаемое время выполнения: 2-4 дня

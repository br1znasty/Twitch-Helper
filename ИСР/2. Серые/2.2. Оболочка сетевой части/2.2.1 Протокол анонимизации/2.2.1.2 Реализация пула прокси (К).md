Требование:
Реализовать модуль управления пулом прокси:
  1. ProxyPool — компонент, загружающий список прокси из таблицы proxies в БД
  2. Метод acquire(): выдать свободный прокси боту (статус → занят)
  3. Метод release(id): освободить прокси после отключения бота (статус → свободен)
  4. Метод markDead(id): пометить прокси как нерабочий при ошибке подключения
  5. Healthcheck: периодически проверять мёртвые прокси и возвращать рабочие в пул
  6. Если свободных прокси нет — выбрасывать понятное исключение с сообщением для UI

Ожидаемое время выполнения: 2-3 дня

Требование:
Написать полноценный интеграционный тест с реальной (тестовой) PostgreSQL:
  1. Использовать Testcontainers: поднимать PostgreSQL в Docker-контейнере
     автоматически перед тестами (@Testcontainers + @Container)
  2. Тест полного цикла auth: register → login → me → updateProfile → logout
  3. Проверить, что данные действительно сохранились в БД (через Repository напрямую)
  4. Тест: два пользователя регистрируются с одним email → второй получает ошибку
  5. Тест: после logout сессия недействительна (GET /api/auth/me → ошибка)
  6. Тест полного цикла статистики (с MockTwitchServer вместо реального Twitch):
     register → login → updateProfile (clientId/Secret) → getStatistics → корректный ответ

Ожидаемое время выполнения: 2-3 дня

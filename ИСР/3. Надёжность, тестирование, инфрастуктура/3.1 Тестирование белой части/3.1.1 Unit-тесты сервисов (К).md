Требование:
Написать unit-тесты для AuthService и TwitchService (JUnit 5 + Mockito).
Уже есть AppApplicationTests — только проверка контекста, этого недостаточно.

AuthService — покрыть сценарии:
  1. register(): успешная регистрация → пользователь сохранён в БД
  2. register(): дубликат username → выброс исключения
  3. register(): дубликат email → выброс исключения
  4. login(): верные credentials → сессия установлена, возвращён AuthResponse
  5. login(): неверный пароль → выброс исключения
  6. login(): несуществующий пользователь → выброс исключения
  7. logout(): сессия инвалидируется
  8. updateProfile(): clientId/clientSecret обновляются корректно

TwitchService — покрыть сценарии:
  1. getStatistics(): нет userId в сессии → Unauthorized
  2. getStatistics(): пользователь без clientId → исключение с понятным сообщением
  3. getStatistics(): пустой список метрик → исключение
  4. getStatistics(): успешный вызов → TwitchCollector вызван с нужными параметрами

Все зависимости мокируются через @Mock / @InjectMocks.

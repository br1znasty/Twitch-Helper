Требование:
Провести ручное тестирование фронтенда и зафиксировать результаты в тех. доке.
Тестировать в браузере при запущенном Docker Compose.

Сценарии (для каждого: шаги + ожидаемый результат + фактический результат):

  Auth:
  1. Регистрация с валидными данными → перенаправление на главную
  2. Регистрация с уже занятым email → понятная ошибка на странице (не alert, не стектрейс)
  3. Вход с верными данными → сессия сохранена, главная доступна
  4. Вход с неверным паролем → понятная ошибка
  5. Обновление страницы после входа → остаёмся залогинены (сессия не сбрасывается)
  6. Logout → редирект на welcomePage, главная недоступна без повторного входа

  Дэшборд:
  7. Выбрать метрики, ввести канал → статистика отображается
  8. Ввести несуществующий канал → оффлайн-состояние, не крашится
  9. Не вводить никаких метрик → ошибка или подсказка, запрос не отправляется
  10. Автообновление: данные меняются без перезагрузки страницы (если реализовано)

  Settings:
  11. Сохранить clientId/clientSecret → данные сохранились (проверить через повторный вход)

Результат: чеклист в тех. доке, баги оформлены как новые задачи в ИСР.

Ожидаемое время выполнения: 1 день

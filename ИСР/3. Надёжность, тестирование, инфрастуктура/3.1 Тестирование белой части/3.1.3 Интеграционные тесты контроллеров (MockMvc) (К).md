Требование:
Написать интеграционные тесты для AuthController и TwitchController
через @WebMvcTest + MockMvc (БД не нужна, сервисы мокируются).

AuthController — покрыть HTTP-уровень:
  1. POST /api/auth/register — валидный body → 200 OK + AuthResponse
  2. POST /api/auth/register — невалидный body (нет email) → 400 Bad Request
  3. POST /api/auth/login — корректные credentials → 200 OK
  4. POST /api/auth/login — неверный пароль → ожидаемый статус ошибки (401/400)
  5. GET /api/auth/me — без сессии → ошибка
  6. POST /api/auth/logout → 200 OK, сессия удалена
  7. PUT /api/auth/profile — обновление clientId/clientSecret → 200 OK

TwitchController:
  1. POST /api/twitch/statistics — без сессии → Unauthorized
  2. POST /api/twitch/statistics — нет credentials у пользователя → ошибка
  3. POST /api/twitch/statistics — корректный запрос → TwitchStatsResponse
  4. POST /api/twitch/statistics — пустой список metrics → 400

Дополнительно: убедиться, что GlobalExceptionHandler корректно
форматирует все ошибки в ErrorResponse (не стектрейс в теле ответа).

Требование:
Финальный end-to-end тест всей серой части через Docker Compose + mock IRC сервер.
Тест автоматизирован (не ручной): запускается одной командой и выдаёт pass/fail.

Сценарий теста:
  1. Поднять Docker Compose (db + backend)
  2. Через REST API: зарегистрироваться, залогиниться
  3. Через REST API: запустить 5 ботов на тестовый канал (mock IRC сервер)
  4. Подождать 60 секунд
  5. Через REST API: получить статус ботов → все 5 активны
  6. Проверить лог mock IRC сервера: каждый бот отправил хотя бы одно сообщение
  7. Проверить bot_logs в БД: есть записи context_changed и message_sent
  8. Через REST API: остановить всех ботов
  9. Проверить mock IRC сервер: получены PART от всех 5 ботов
  10. Проверить статус ботов: все остановлены

Результат: тест запускается в CI-пайплайне (GitHub Actions или просто скрипт),
выдаёт PASS/FAIL с логом.

Ожидаемое время выполнения: 2-3 дня

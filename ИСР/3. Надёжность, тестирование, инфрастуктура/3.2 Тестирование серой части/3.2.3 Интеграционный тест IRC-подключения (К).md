Требование:
Написать интеграционный тест IRC-клиента без реального Twitch — через локальный mock IRC сервер.

Реализация:
  1. Поднять простой TCP-сервер в тесте (ServerSocket), имитирующий IRC-протокол Twitch:
       - принимает PASS/NICK/JOIN
       - отвечает на PING → PONG
       - принимает PRIVMSG и записывает в список
  2. Тест: бот подключается к mock-серверу → успешный JOIN
  3. Тест: бот отправляет PRIVMSG → сервер получил сообщение
  4. Тест: mock-сервер шлёт PING → бот отвечает PONG в течение 2 секунд
  5. Тест: mock-сервер обрывает соединение → бот логирует disconnect, не крашится
  6. Тест: mock-сервер возвращает :tmi.twitch.tv NOTICE * :Login authentication failed
     → бот помечает аккаунт как недоступный

Ожидаемое время выполнения: 2-3 дня

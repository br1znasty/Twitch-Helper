Требование:
Написать unit-тесты для MessageDispatcher.

Покрыть сценарии:
  1. getNextMessage(context): возвращает сообщение подходящего контекста из БД
  2. getNextMessage(): взвешенная выборка работает — сообщение с weight=10 выбирается
     чаще чем с weight=1 (запустить 1000 раз, проверить распределение ±20%)
  3. Два бота не получают одно сообщение в одну минуту (no-duplicate guard)
  4. Один бот не получает одно сообщение дважды в течение часа (history guard)
  5. В БД нет сообщений для данного контекста → возвращается fallback или исключение
  6. getNextMessage(): context=null → fallback на generic тип контекста

Ожидаемое время выполнения: 1-2 дня

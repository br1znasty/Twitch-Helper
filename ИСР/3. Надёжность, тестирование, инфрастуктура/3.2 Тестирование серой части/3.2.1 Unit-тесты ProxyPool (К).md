Требование:
Написать unit-тесты для компонента ProxyPool (JUnit 5 + Mockito).

Покрыть сценарии:
  1. acquire(): есть свободный прокси → возвращает прокси, статус меняется на "занят"
  2. acquire(): все прокси заняты → выбрасывает NoProxyAvailableException
  3. acquire(): все прокси мёртвые → выбрасывает NoProxyAvailableException
  4. release(id): прокси возвращается в пул (статус → свободен)
  5. release(id): несуществующий id → ошибка не роняет систему (тихий лог)
  6. markDead(id): прокси помечается мёртвым и не выдаётся через acquire()
  7. Healthcheck: мёртвый прокси проверяется и возвращается в пул если ожил
  8. Потокобезопасность: 30 потоков одновременно вызывают acquire() →
     каждый получает уникальный прокси, нет гонки данных

Ожидаемое время выполнения: 1-2 дня

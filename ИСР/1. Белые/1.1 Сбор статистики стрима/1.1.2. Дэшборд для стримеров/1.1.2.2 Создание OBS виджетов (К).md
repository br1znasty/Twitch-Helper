Требование:
Реализовать HTML-виджеты для OBS Browser Source. Каждый виджет — это отдельный
эндпоинт на бэкенде, возвращающий самодостаточную HTML-страницу:
  1. Реализовать минимум 2 виджета: счётчик зрителей и статус стрима
  2. Страница виджета сама опрашивает бэкенд с заданным интервалом (JS fetch)
     и обновляет отображение без перезагрузки
  3. Прозрачный фон, стилизованный под стрим (CSS переменные для кастомизации)
  4. Параметры виджета передаются через query string: /widget/viewers?channel=имя&interval=30
  5. Виджет должен корректно вести себя при оффлайн-канале

Ожидаемое время выполнения: 2-3 дня
